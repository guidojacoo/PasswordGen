Actividad diagnóstico Frontend
Crear una página web estática utilizando Astro.
Entrega: repositorio de gitHub + defensa oral (a discreción del docente).
Duración: 2 semanas
Requisitos mínimos
● 1 página principal
● al menos 3 secciones
● responsive básico
● algún comportamiento con JavaScript
Opcional (crédito extra)
● componentes reutilizables
● animaciones
● librerías CSS
● fetch de API
● dark mode
● deploy
● integración con otras librerías
Entrega
El repositorio de gitHub debe contar con:
● código
● Commits progresivos
● README con:
○ explicación del proyecto
○ herramientas usadas
○ instrucciones para ejecutarlo
Bonus
Deploy en: Vercel o Netlify
Anexo:
Conceptos a evaluar
● Correcta estructuración del HTML y utilización de HTML semántico
● Elección y aplicación correcta de herramientas CSS
● Utilización de JS básico (eventos, manipulación de DOM, fetch a APIs externas)
● Estructura de archivos del proyecto correcta
● Correcta utilización del repositorio de github
Ideas de desarrollo
1. Dashboard
Ejemplos:
● clima
● hábitos
● entrenamiento
● estudio
Con: cards, gráficos simples, estado.
2. Catálogo
● videojuegos
● películas
● música
● animales
● comidas
Con: CSS Grid, filtros, búsqueda.
3. Mini App
Ejemplos:
● generador de contraseñas
● lista de tareas
● temporizador pomodoro
● generador de colores
● conversor de unidades
